# Medical Workspace Design

Änderungen: neue öffentliche Startseite (`src/routes/+page.svelte`), neues Dashboard, neues App-Layout und globale Styles. Die bisherige Root-Weiterleitung wurde entfernt, damit `/` die öffentliche Seite anzeigt. Authentifizierung, Datenbank und bestehende Features bleiben erhalten.

## Start
`npm install` und `npm run dev`. Für Login, Registrierung und geschützte Bereiche muss die Datenbank wie in README beschrieben eingerichtet sein.

## Hinweis
Das ist eine organisatorische Demo, kein zertifiziertes Medizinprodukt. Keine echten Patientendaten verwenden. Für den produktiven klinischen Einsatz sind Datenschutz-, Sicherheits-, Barrierefreiheits- und regulatorische Anforderungen separat zu prüfen.
